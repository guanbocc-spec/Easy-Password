# Easy Password 使用手册（简体中文）

> 语言：[English](USER_GUIDE.en.md) · 简体中文（当前）
>
> 一个**纯本地、不联网、不收集你任何信息**的浏览器密码管家。
> 主打三件事：**简单**、**本地**、**离线**；并为内网运维准备了一套高效工作台。

---

## 0. 我们的承诺（请先读这一段）

- **纯本地**：你的账号、密码、域名全部加密后只存在你自己的浏览器里，**永不离开本机**。
- **不联网**：扩展运行期间**不发起任何网络请求**（连用于加密的 Argon2id 算法都是内置的）。
- **不收集**：**不收集、不上传、不分析**你的任何信息，没有账号体系、没有服务器、没有统计。
- **唯一的“联网”动作**：只有你**亲手点「导出加密备份」**并自行通过网盘/U 盘传输时，文件才离开本机——而且导出的本身就是密文。

一句话：**装上它，断网也能用。**

---

## 1. 安装与授权

1. 打开扩展管理页：Chrome 为 `chrome://extensions`，Edge 为 `edge://extensions`。
2. 打开右上角 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择 `easy-password` 文件夹。
4. 工具栏出现 🔐 图标即安装成功。建议固定在工具栏上。
5. 点击 🔐 图标，按顶部提示点 **授权**，开启网页上的自动提示 / 回填 / 保存。

> **为什么要点一次「授权」？** 为把权限降到最小、保护隐私，扩展**安装时不申请任何网站权限**。
> 只有你亲手点「授权」后它才会在网页上工作；不授权也能在弹窗里手动管理密码。随时可在扩展详情页收回该权限。
> 界面语言跟随浏览器语言自动切换（简体中文 / 英文）。

---

## 2. 第一步：创建主账户

第一次点 🔐 图标会让你**创建主账户**：

1. 设 **主账户名**（随便起，用于标识你自己）。
2. 设 **主密码**（至少 6 位，**务必牢记**）。
3. 点 **创建并解锁**。

主密码是整个密码库的总钥匙：

- 它**不保存在任何地方**，只用来加密/解锁你的数据。
- **忘记主密码 = 无法找回已存密码**（这正是它安全的原因）。请用一句你不会忘、别人猜不到的长口令。
- 创建/解锁时会**卡顿零点几秒**属正常——这是 Argon2id 在用算力抵抗暴力破解。

创建完成即进入**已解锁**状态。

## 3. 日常使用

### 3.1 自动记住账号密码

1. 在任意网站正常输入账号密码登录。
2. **点「登录 / 提交」后**，右上角弹卡片：「是否保存账号『xxx』的密码？」
3. 点 **保存** 即把这条**加密存入**密码库。

> 只在**提交之后**才提示，输入/切换输入框过程中不打扰。
>
> **手机号/邮箱 + 验证码登录（无密码）也能记**：会弹「是否记住本站账号」，点「记住」即只记账号。
> 甚至 **`root` + 空密码** 这种无密码登录也会提示记住账号。模型是「**域名 → 提示账号；选中账号 → 有密码就回填**」。

### 3.2 账号提示与自动回填

1. 再来该网站登录页——若已存过账号，**打开页面就自动填好账号和密码**（多账号填最近用的那个）。
2. 想换账号：点账号框，输首字符（支持中文）弹出匹配下拉；↑↓ 选、回车确认，或直接点选——对应**密码自动解密填好**。
3. **内网 / 无域名站点**：用 `IP:端口`（如 `192.168.1.10:8080`）作标识，不同端口当作不同应用分别记忆。

> 注册 / 改密页不会自动填账号，以免干扰你创建新账号。

### 3.3 强密码生成器（注册 / 改密）

1. 在注册页或改密页点**新密码框**，自动弹出生成器。
2. 选**长度**（12~32）、看**实时强度条**。
3. 点 **使用** 把强密码填入（连同“确认密码”框一起填）；不满意点 **换一个**。

> 生成的密码在反复点击间**保持不变**，方便逐字核对确认框；只有点「换一个」或改长度才更换。
> 弹窗的新增表单里也有 🔑 一键生成。

## 4. 锁定与定时身份确认

防止他人趁你离开翻看密码，Easy Password 会**定时上锁**：

- 解锁后有**有效期**（默认 30 分钟，可在设置里改）。
- **超时或关浏览器后自动锁定**，需重新输入主密码确认身份。
- 锁定期间，网页上聚焦登录框会提示「已锁定，点工具栏 🔐 图标确认身份」。点图标输主密码即解锁。
- 可随时点弹窗右上角 **锁定** 立即上锁。

## 5. 管理你的密码（点 🔐 图标）

弹窗主界面：

- **新增**：默认收起，点「＋ 新增账号」展开。填域名（留空＝当前标签页）、账号、密码（**可留空＝只记账号**）、可选「备注 / 分组 / 完整登录 URL」，点 **加密并保存**。
- **搜索**：按账号 / 域名 / **备注** / 分组快速过滤。
- 每条目操作：
  - **🚀**（若存了完整 URL）：新标签直达登录页并自动回填，见 §6.1。
  - **显示 / 复制**：看密码 / 复制密码到剪贴板。
  - **📝 编辑**：改备注或分组。
  - **删除**：移除该条。
  - **点账号文字** = 直接复制账号到剪贴板（运维常用，账号也要贴）。
- **加密备注**：每条可写一句说明（如“堡垒机 root，季度轮换”），同样加密存储、可被搜索。

## 6. 高级：内网运维工作台

> 普通用户**默认无感**：不建分组、不开颜色，就是上面的极简体验。以下是给高频运维准备的提效/防错功能。

### 6.1 🚀 全路径直达

内网后台地址常又长又怪（如 `:8030/ui/#/dc1`），只记 IP 进不到登录页。
- 在该登录页保存账号时会**自动记下完整 URL**（也可在新增表单手填）。
- 点列表里的 **🚀** → 新开标签直接打开该 URL → 落地后按 IP:端口自动回填账号密码。

### 6.2 📌 侧边栏常驻

默认弹窗点一下网页就关，不便比对/复制。
- 点弹窗头部 **📌** → 把界面**固定到浏览器侧边栏**，常驻不关。
- 侧边栏会**随标签页切换实时刷新**：自动识别当前 `IP:端口`，把匹配的账号顶到最前；顶部「当前站点」可**点击复制**；新增框的域名也跟着当前页变。

### 6.3 分组 + 一键全部启动

- 给条目填**分组**（如“生产巡检”“测试环境”），列表按分组归拢。
- 分组**默认折叠**，只看到组名（点组名展开/收起，状态会记住）。
- 组头「**全部启动 🚀**」：把该组里所有带 URL 的系统**在后台批量打开**（不抢当前焦点）。
- **防误触气囊**：一组超过 8 个会先 `confirm` 让你确认，避免一次开太多崩溃浏览器。

### 6.4 🎨 颜色环境警告（防“在生产敲了测试命令”）

- 在分组头的三色点把分组设为 **🔴 红（生产/危险）** 或 **🟢 绿（测试/安全）**，**无色**则不标记。
- 被标记分组里的站点，页面会出现一圈**全屏呼吸边框**（红/绿），熬夜也一眼看清环境；边框**鼠标可穿透**，绝不挡你点任何按钮。
- **站点单独覆盖（优先级高于分组）**：设置区「站点环境标记」可对某个 `host:端口` 或域名单独设色，**支持通配符**：
  - `*.baidu.com`（该域名下所有子域）
  - `10.4.*.*`（该网段所有 IP，任意端口）
  - `10.0.0.1:8080`（精确到端口）
- 无色分组、且无任何标记时，**绝不向网页注入任何东西**，保持纯净。

### 6.5 🧹 清除并禁用浏览器自带「记住密码」

设置区红色按钮「**清除并禁用浏览器自带密码**」：一键**清空浏览器已保存的全部密码**，并**关掉它的「提示保存密码」**——免得它和本扩展重复弹、也清掉旧的明文记录。
- 点击会**二次确认**（不可恢复），并**当场申请所需权限**（不用时不索取）。
- 注意：清的是**浏览器自带**的密码库，不是本扩展的库。

## 7. 设置区（弹窗底部）

- **站点环境标记**：见 §6.4。
- **清除并禁用浏览器自带密码**：见 §6.5。
- **自动锁定**：选 5 / 15 / 30 / 60 / 120 分钟。越短越安全。
- **活动时自动续期**：开启后只要在用密码库就顺延到期时间；纯发呆才到点锁定。
- **改主密码**：在**同一页**填「当前 + 新 + 确认」一次提交。已存账号不受影响、无需重录。
- 「主密钥派生：Argon2id」字样表示加密引擎正常。

## 8. 备份与换电脑

数据**只在本机、不会自动同步**，换设备用加密备份手动迁移：

1. 旧设备：弹窗 **导出加密备份** → 得到 `easy-password-backup.json`。
2. 新设备：装好扩展 → **导入备份** 选该文件 → 按提示**输入该备份的主密码**解密。
3. 导入后要求**重新解锁**：输入**原设备的主账户名 + 主密码**即可。

> 备份文件**整体用主密码加密**：连主账户名、存了几条、涉及哪些网站都看不出，里面只有解密用的盐/参数 + 密文。
> 没有主密码完全打不开，可放心通过网盘 / U 盘传输。

**每周提醒**：每到周一（且本周还没备份、库非空）打开弹窗会弹「每周备份提醒」，点 **立即备份** 下载本周备份；
**导出成功后提醒才消失**。点「稍后」本次关闭，下次打开仍提醒。

## 9. 常见问题（速查）

- **忘记主密码？** 无法找回。只能移除扩展、重新创建主账户（会丢已存数据，除非有可解锁的备份）。
- **会上传数据吗 / 多设备自动同步吗？** 不上传、全程本地；不自动同步，用加密备份手动迁移。
- **卸载会丢数据吗？** 会，先导出备份。
- **某站点不弹保存 / 提示？** 个别站点表单结构特殊可能识别不到，可在弹窗**手动新增**。
- **改了设置/功能没生效？** 多数是**扩展没重新加载**——到 `chrome://extensions` 点该扩展的「重新加载」，光刷新网页不够。
- **创建账户报错 / 派生不是 Argon2id？** 该浏览器没能执行 WASM，请用较新版 Chrome/Edge。
