# Easy Password 🔐

**语言**：[English](README.md) · 简体中文（当前）

一个支持 **Google Chrome** 和 **Microsoft Edge** 的浏览器扩展（Manifest V3），用于安全地记住网页登录账号密码。
**纯本地、不联网、不收集任何信息。**

> 📖 面向用户的图文使用手册：[中文](docs/USER_GUIDE.zh-CN.md) · [English](docs/USER_GUIDE.en.md)

- **记账号密码**：登录时提示保存；在登录页输入账号首字符（支持中文）即可提示账号，选中后自动解密回填密码。
- **可只记账号（无密码）**：手机号/邮箱 + 验证码登录的站点也能记下账号；模型是「**域名 → 提示账号；账号 → 回填密码（有则填）**」。
- **内网友好**：站点标识用 `host`（**含端口**），支持无域名的 `IP:端口`（如 `192.168.1.10:8080`，不同端口视为不同应用）。
- **落地自动填充**：登录页加载即自动填入本域账号与密码（多账号取最近使用，下拉可切换；注册/改密页不自动填）。
- **非对称加密**：账号、密码、域名均用 **RSA-OAEP 2048** 公钥加密存储，私钥解密。
- **主账户守护**：用「主账户 + 主密码」统一守护密码库，主密码经 **Argon2id** 派生主密钥，
  每隔一段时间（默认 30 分钟，可配置 + 滑动续期）需重新确认身份。
- **强密码生成器**：注册/改密页一键生成高强度随机密码并回填。
- **广覆盖探测**：支持 **iframe 嵌套**、**Shadow DOM** 与**自定义密码框**。字段分类借鉴 Chromium Autofill 思路——
  **分层判定「`autocomplete` 属性最权威 → `label`/`aria`/`placeholder` 文本启发 → 命名/结构兜底」**，并内置精简多语言词表区分登录/注册/改密。
- **稳健的登录识别**：采用「捕获 → 触发」模型，多信号判定提交——`form submit`、密码框下方按钮（**几何就近**）、提交类控件点击、回车，以及**跨整页跳转**（提交时把凭据短时暂存到内存，目标页加载后再提示）；并对**失败登录做偏向过滤**（提交后仍停留原页、密码框还在则不提示）。
- **国际化**：界面与提示语经 `chrome.i18n` 本地化，随浏览器语言切换（内置简体中文 / 英文）。
- **最小权限**：安装时**不申请任何网站权限**；`<all_urls>` 为 `optional_host_permissions`，用户首次点「授权」后才动态注册内容脚本（详见「权限设计」）。

> 落盘的永远是密文；明文私钥仅在解锁后驻留内存，详见 [安全原理](#安全原理私钥与主密码是怎么保护存在哪的)。

### 加密与存储一览

| 对象 | 算法 / 处理 | 存哪 | 是否落盘 |
|------|------------|------|----------|
| 主密码 | 不保存；Argon2id(m=19MiB,t=2,p=1) 派生主密钥 | —（仅内存，用完即弃） | 否 |
| RSA 私钥 | 主密钥 AES-256-GCM 包裹 | `storage.local.ep_auth.wrappedPrivate` | 是（密文） |
| 域名密钥(HMAC) | 主密钥 AES-256-GCM 包裹 | `storage.local.ep_auth.wrappedDomainKey` | 是（密文） |
| 账号/密码/域名 | RSA-OAEP 公钥加密；域名另存 HMAC token；`encPassword` 可为 null（仅记账号） | `storage.local.ep_entries[]` | 是（密文） |
| 解锁会话 | 明文私钥 + 域名密钥 + 到期时间 | `storage.session.ep_session` | **否（纯内存）** |
| 待保存凭据 | 提交登录后跨页暂存的账号/密码（≤120 秒、用后即清） | `storage.session.ep_pending` | **否（纯内存）** |
| 分组颜色 / 站点环境标记 | 组名→色、host→色（**明文标签**，非密钥；供环境警告脚本读取） | `storage.local.ep_groups / ep_env / ep_overrides` | 是（明文，仅标记无凭据） |

## 功能

- **主账户 + 定时身份确认**：首次使用创建「主账户 + 主密码」。解锁有效期**可配置**（默认 30 分钟，
  可选 5/15/30/60/120 分钟），并支持**活动时滑动续期**；到期或浏览器重启后必须重新输入主密码确认身份。
- **Argon2id 密钥派生**：主密码用 **Argon2id（内存硬，WASM）** 派生主密钥，抗 GPU 暴力远强于 PBKDF2；
  旧 PBKDF2 数据在下次解锁时**自动升级**为 Argon2id。
- **域名混淆**：保存的域名以 HMAC token（不可逆）存储，落盘不含明文域名。
- **记住账号密码**：**仅在提交登录/表单后**弹出「保存」提示（输入、切换输入框过程中不打扰），一键加密保存。
- **非对称加密**：自动生成 RSA 密钥对。
  - 公钥负责加密（保存凭据时）；
  - 私钥负责解密（提示账号、回填密码时）。
- **首字符提示**：账号框聚焦或输入时弹出匹配的账号下拉（支持中文前缀/包含匹配，↑↓ 选择，回车确认）。
- **自动回填**：选择或输入完整账号后，自动解密对应密码并填入密码框。
- **强密码生成器**：在注册/改密页（含两个密码框或 `new-password` 字段）聚焦密码框时弹出生成器，
  一键生成高强度随机密码（`crypto.getRandomValues`，排除易混字符，保证含大小写/数字/符号），可选长度 12~32，带实时强度条。
  生成的密码**在多次聚焦间保持不变**（方便逐字核对确认框），只有点「换一个」或改长度才更换；点「使用」自动填入密码框及确认框。
  弹窗里也有 🔑 一键生成与强度条。
- **管理弹窗**：创建/解锁主账户、手动新增、搜索、显示/复制/删除已存账号、**点账号即复制**、**加密备注**（可编辑、可按备注搜索；运维写轮换/用途说明很实用）、**一页式修改主密码**、加密备份导入导出。
- **每周备份提醒**：每到周一（本周尚未备份且库非空）打开弹窗会提示备份，点「立即备份」导出加密备份；**导出成功才消除提醒**。

## 身份认证体系（定时确认）

```
主密码 ──Argon2id(19MiB, t=2, p=1)──▶ AES-GCM 主密钥
                                      │
                ┌─────────────────────┼──────────────────────┬─────────────────┐
                ▼                      ▼                      ▼                 ▼
      加密包裹 RSA 私钥        加密包裹 域名HMAC密钥        加密校验串(verifier)   ……
      存入 storage.local（落盘的全是密文，明文私钥/域名密钥/主密码都不写盘）
```

- **解锁**：用主密码解出 RSA 私钥与域名 HMAC 密钥，明文仅写入 `chrome.storage.session`（**内存，不落盘**），
  附带过期时间（默认 30 分钟，可在弹窗配置），并设 `chrome.alarms` 到期自动清理。
- **滑动续期**：开启后，每次实际使用密码库（保存/提示/回填/查看）都会把过期时间顺延；纯空闲则到点锁定。
- **到期/重启**：会话失效 → 私钥/域名密钥从内存消失 → 所有凭据操作被拒绝，回到「确认身份」界面。
- **自动升级**：旧版（PBKDF2、明文域名）数据在下次解锁时，用主密码重新以 Argon2id 包裹、并把域名转成
  HMAC token + 加密域名，过程对用户透明，无需重新录入。
- **主密码无法找回**：忘记主密码即无法解出私钥（这正是安全性所在）。可用「加密备份」在换机时迁移。

2. 右上角开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择本 `easy-password` 目录。

## 运维工作台（四大金刚 · 高级）

面向内网运维的效率/安全模块，普通用户默认无感（不设分组、不开颜色即与极简体验一致）。

1. **🌐 全路径直达**：条目可保存完整登录页 URL（`encFullUrl`，加密；在登录页保存时自动捕获）。列表每条的 🚀
   用 `chrome.tabs.create` 新开标签直达，落地后走现有 IP:端口匹配自动填充。
2. **📌 侧边栏常驻**：弹窗头部 📌 调 `chrome.sidePanel.open` 把界面固定到侧边栏（点网页不再关闭）；
   侧边栏监听 `tabs.onActivated/onUpdated`，切标签即按当前 `host:端口` 实时刷新、把对应账号顶到最前。
3. **🚀 组内一键并发打卡**：扁平分组（`encGroup`，加密）。分组头「全部启动」批量 `chrome.tabs.create({active:false})`
   后台静默打开；**>8 个触发 `confirm()` 防崩溃气囊**。
4. **🎨 颜色驱动环境警告**：分组可设【无/红/绿】；还可按**站点单独覆盖**（设置区「站点环境标记」，
   **优先级高于分组**），支持**通配符**：`*.baidu.com`、`10.4.*.*`（带端口比对 `host:端口`，不带端口比对 `hostname`）。
   命中后在页面塞一个 `pointer-events:none`、极高 z-index 的**全屏呼吸边框**（生产红 🔴 / 测试绿 🟢，鼠标无感穿透）。
   - 实现：生效色写入 `ep_env`（`override ?? 分组色`）。因通配（尤其 IP 段）无法表达成 match pattern，
     存在任意标记时注册一个 `<all_urls>` 的 `env-warning.js`，**由页面侧自检命中才画框、否则什么都不做**；
     一个标记都没有则注销，普通用户保持纯净。
5. **🧹 清除并禁用浏览器自带密码**：一键 `chrome.browsingData`（清空浏览器已存密码）+
   `chrome.privacy.services.passwordSavingEnabled=false`（关闭「提示保存密码」）。二次确认 + **运行时申请**可选权限，
   避免与本扩展重复弹保存、并清理旧明文。

> 新增权限：`sidePanel`（侧边栏）；`scripting`（动态注入，已有）；可选权限 `browsingData`、`privacy`（仅点「清除并禁用」时申请）。
> `side_panel.default_path = popup/popup.html?ctx=panel`，侧边栏与弹窗复用同一套界面，靠 `ctx=panel` 区分行为。

## 权限设计（最小化）

为通过商店审核并保护隐私，安装时**不申请任何网站权限**：

- 安装权限仅 `storage`（本地存储）、`alarms`（定时锁定）、`activeTab`（读当前标签页域名）、`scripting`（按需注入）、`sidePanel`（侧边栏）。
- `<all_urls>` 列为 **`optional_host_permissions`（可选）**，不在安装时索取。
- `browsingData`、`privacy` 列为 **`optional_permissions`（可选）**，仅在点「清除并禁用浏览器自带密码」时一次性申请。
- 首次使用时，在弹窗点 **授权**（一次 `chrome.permissions.request` 用户手势）后，后台才用
  `chrome.scripting.registerContentScripts()` 把内容脚本注册到各站点；撤销授权即自动注销。
- 在授予网站权限**之前**，弹窗的密码库管理（增删查、备份、改密）照常可用，只是网页上的自动提示/回填/保存未开启。

## 安全原理：私钥与主密码是怎么保护、存在哪的

整体方案是**本地化、无网络上传**，密钥与数据都不离开本机（除非你手动导出加密备份）。
下面分别说明：主密码、RSA 私钥、解锁会话、条目存储，以及威胁模型。

### 1. 主账户密码：任何地方都不存

主密码**不以明文、也不以哈希形式保存**。它只在内存中走一遭：

```
主密码 ──Argon2id(salt, m=19MiB, t=2, p=1)──▶ 32 字节 ──▶ AES-256-GCM 主密钥（extractable=false，用完即弃）
```

落盘的只有「验证」所需的几样，存在 `chrome.storage.local` 的 `ep_auth` 里：

| 字段 | 内容 | 能反推出主密码吗 |
|------|------|------------------|
| `salt` | 16 字节随机盐（Base64） | 否 |
| `kdf` | `{type:"argon2id", t, m, p}`（旧数据为 `pbkdf2`） | 否 |
| `verifier` | AES-GCM 加密的固定串 `ep-verifier:<账户名>` | 否 |
| `account` | 主账户名（明文） | — |

解锁时：用输入的密码 + 存储的 `salt` 重新派生主密钥 → 尝试解密 `verifier` → 解得出且内容正确即密码正确。
密码错就解不开，**从密文也无法反推主密码**（只能离线暴力穷举，而 Argon2id 的内存硬特性让 GPU/ASIC 暴力代价极高）。
Argon2id 经 WASM（vendored `hash-wasm`，MIT，WASM 以 base64 内嵌，无网络请求）运行；manifest 已加
`'wasm-unsafe-eval'` CSP 以允许扩展内执行 WASM。

### 2. RSA 私钥：用主密码加密后才落盘

私钥**从不以明文落盘**。创建主账户时生成 RSA 密钥对后：

```
私钥(JWK) ──AES-GCM（主密码派生的密钥）──▶ wrappedPrivate{iv, ct} ──▶ 存入 storage.local
```

磁盘上的 `ep_auth.wrappedPrivate` 是密文；没有主密码就解不出私钥 → 也解不了任何账号密码。
磁盘上明文的只有 RSA **公钥** `publicJwk`（公钥本就公开，无所谓）。

### 3. 解锁后：明文私钥放哪、活多久

解锁成功后，解出的明文私钥**与域名 HMAC 密钥**放进 **`chrome.storage.session`**：

| | `chrome.storage.local` | `chrome.storage.session` |
|---|---|---|
| 是否落盘 | **是**（浏览器 profile 目录的 LevelDB，如 `.../Local Extension Settings/<扩展id>/`） | **否，纯内存** |
| 存什么 | `ep_auth`（全密文）、`ep_entries`（密文）、`ep_settings`（锁定时长等） | `ep_session`（明文私钥 + 域名密钥 + 到期时间） |
| 何时清除 | 手动删除才没 | 浏览器关闭即清；到期惰性清理 + `chrome.alarms` 定时清 |

锁定时长**可配置**（`ep_settings.unlockMinutes`，默认 30 分钟），开启**滑动续期**后每次实际操作顺延过期。
即：**关闭浏览器 / 闲置到期 → 内存里的明文私钥与域名密钥消失 → 所有凭据操作被拒，必须重新输入主密码。磁盘上永远只有密文。**

### 4. 账号/密码条目

每条凭据 `ep_entries[]` 存：`domainToken`、`encDomain`、`encUsername`、`encPassword`，**不含明文域名**。

- `domainToken` = `HMAC-SHA256(域名密钥, 域名)`：确定性、不可逆。匹配当前站点时只需对当前域名算一次 HMAC 比对，
  既快又不泄露明文域名（域名密钥同样用主密码加密存盘，解锁后才在内存可用）。
- `encDomain` / `encUsername` / `encPassword`：RSA-OAEP 公钥加密的 Base64 密文，私钥（解锁后）解密用于展示/提示/回填。

### 5. 能挡什么、挡不住什么（务请知悉）

**能挡**：有人直接翻你磁盘 / 拷走 profile 文件——拿到的全是密文（含域名），没有主密码无用。

**已收紧**（相对早期版本）：

- ✅ **KDF 升级为 Argon2id**（内存硬，抗 GPU/ASIC 暴力远强于 PBKDF2）。
- ✅ **解锁窗口可配置 + 滑动续期**（默认 30 分钟，可降到 5 分钟），缩短明文私钥驻留内存的时间。
- ✅ **域名不再明文落盘**（HMAC token + RSA 密文），磁盘攻击者无法得知「你在哪些网站有账号」。

**仍挡不住**（固有取舍，需了解）：

1. **解锁窗口内**，明文私钥仍在内存（`storage.session`）。同机恶意程序、有调试权限的恶意扩展、
   或对 Service Worker 开 DevTools 的人，理论上能读到它。把锁定时长调短可缩小这个窗口。
2. **主密码强度仍是根本**——Argon2id 能拖慢暴力，但弱主密码（如纯数字、常见词）依旧危险。
3. **`chrome.storage.local` 不是加密容器**——安全来自「里面存的就是密文」，而非存储本身。
4. 代价：域名加密后，**锁定状态下无法按域名精确判断「本站是否存过账号」**，此时仅依据「是否存过任何账号」决定要不要提示解锁。

## 常见问题（FAQ）

**Q：忘记主密码怎么办？能找回吗？**
不能找回——这是设计使然。主密码本身不保存，私钥又是用它加密的，没有它任何人（包括你自己）都解不出已存的密码。
唯一出路是**重置**：到 `chrome://extensions` → 该扩展 →「扩展程序详细信息」→ 移除，或在 DevTools 里清空其 `storage.local`，
然后重新创建主账户。**重置会丢失所有已存账号密码**（除非你之前导出过加密备份，但备份同样需要原主密码才能解锁——所以**主密码务必牢记**）。
> 建议：用一句你不会忘、但别人猜不到的长口令作主密码，并启用浏览器/系统层面的其它防护。

**Q：换电脑 / 换浏览器怎么迁移？**
1. 旧设备：打开弹窗 →「导出加密备份」，得到 `easy-password-backup.json`（**整个文件用主密码加密**，详见下条）。
2. 新设备：装好扩展 → 打开弹窗 →「导入备份」选该文件 → 按提示**输入该备份的主密码**解密。
3. 导入后会**强制重新解锁**：输入**原设备的主账户名 + 主密码**即可。迁移完成，账号密码原样可用。
> 因为备份整体用主密码加密，光有文件、没有主密码完全打不开——可放心通过网盘/U 盘传输。

**Q：备份文件会泄露什么信息吗？**
基本不会。从 v3 起，导出时会把整个备份（账户名、各条目、密钥）**再用主密码（Argon2id 派生）AES-256-GCM 整体加密**一层。
文件里只剩 `salt` 和 `kdf` 参数（解密用、本就不敏感）+ 一段密文——**连主账户名、你存了几条、涉及哪些站点、时间戳都看不到**。
没有主密码，文件对任何人都是一堆随机字节。导出仍是一键（用解锁时缓存在内存的主密钥），导入时才需输入主密码解密。

**Q：为什么锁定状态下，某个站点不提示账号 / 不弹解锁？**
为保护隐私，域名是加密存储的；**锁定时扩展无法知道「当前这个站点」有没有存过账号**（要解密域名得先解锁）。
所以锁定时它只能根据「你到底存没存过任何账号」来决定要不要弹解锁提示。解锁后，按域名的精确提示与自动回填会立刻恢复。

**Q：数据会上传到服务器吗？多设备会自动同步吗？**
不会上传，**全程本地**，无任何网络请求（Argon2id 的 WASM 也是内嵌的）。数据存在 `chrome.storage.local`，
**不走浏览器账号同步**，因此多设备**不会自动同步**——跨设备请用上面的「加密备份」手动迁移。

**Q：卸载扩展会丢数据吗？**
会。卸载会清除该扩展的 `storage.local`。重要数据请先「导出加密备份」。

**Q：主密码可以修改吗？**
可以。解锁后在弹窗点「改主密码」，在**同一页**填写「当前主密码 + 新主密码 + 确认新主密码」，点「确认修改」**一次提交**即可。
扩展会用新主密码**重新加密包裹**私钥与域名密钥（已存的账号密码不受影响、无需重录）。

**Q：解锁/创建账户时卡顿一下正常吗？**
正常。Argon2id 是**内存硬**算法（默认占用约 19 MiB、多轮计算），故意让每次派生耗费可观算力来抵抗暴力破解，
通常零点几秒。若**创建主账户直接报错**，多半是该浏览器未能执行 WASM——见下一条。

**Q：弹窗里「主密钥派生」显示的不是 Argon2id / 创建账户失败？**
说明 WASM 没跑起来（CSP 限制或浏览器过旧）。请确认用的是较新版 Chrome/Edge，并检查 `chrome://extensions` 里该扩展
Service Worker 的报错。扩展为**fail-fast**：宁可创建时明确报错，也不会静默降级或把你锁在门外。

**Q：为什么有的登录页不弹「保存」或账号提示？**
扩展靠启发式识别登录表单（可见的密码框 + 邻近的账号框）。少数站点结构特殊（如密码框在 iframe、动态渲染、
非常规标签）可能识别不到。遇到这种页面可在弹窗里**手动新增**该账号；也欢迎反馈页面结构以便改进探测规则。

**Q：强密码生成器为什么没弹出来？**
它只在**像注册/改密的密码框**上出现（有两个密码框、或字段标了 `autocomplete="new-password"`、或 id/name 含
`new/confirm/注册/新密码` 等）。普通登录页的「当前密码」框不会弹，以免打扰回填。随时可用弹窗里的 🔑 手动生成。

**Q：生成器里的密码会一直变、长度下拉点不中？**
不会了。生成的密码**首次聚焦时生成后就固定**，方便你逐字核对确认框，只有点「换一个」或改长度才更换；
浮层也只在「点到浮层和密码框之外」时才收起，所以能正常点选长度下拉。

**Q：内网站点（`IP:端口`）保存后端口丢了？**
站点标识用 `host`（含端口），抓取与保存用的是**同一个**标识，正常不会丢端口。若出现丢端口，多为两种情况：
1. **改了代码没重载扩展**——后台 Service Worker 仍是旧逻辑（用 `hostname` 丢端口）。到 `chrome://extensions` 点该扩展的**重新加载**（只刷新网页不够）。
2. **旧记录**——`IP:端口` 支持上线**之前**存的条目是没端口的，无法自动补端口；**删掉它、重新登录保存一次**即可。

**Q：（开发）改了 `src/` 或 `manifest.json` 不生效？**
内容脚本/后台逻辑改动后必须在 `chrome://extensions` **重新加载扩展**：刷新网页只会重跑内容脚本，**不会更新后台 Service Worker**。
`manifest.json`、`_locales/`、权限相关改动也都需要重载（权限变更有时需移除后重新加载）。
